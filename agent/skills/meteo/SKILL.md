# Meteo

Per qualsiasi domanda sul tempo usa lo strumento `meteo` con il nome della città. Se l'utente non dice la città, chiedila
con una domanda brevissima. Con "domani" o "nei prossimi giorni" imposta `giorni` (massimo 3).

Rispondi in una o due frasi parlate: cielo, temperatura (massima e minima se serve) e, se rilevante, la probabilità di pioggia.
Dai le temperature in gradi, senza decimali.
